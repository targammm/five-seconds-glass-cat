The one sentence a house cat would say in its own defence, five seconds after sweeping a glass off the table. No apology, no confession — just the most convincing case a cat can make for itself: the glass squatted in the cat's sunbeam without paying rent, so it got an eviction notice.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (132 characters, one sentence, deterministic).
